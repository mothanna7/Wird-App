# وِرد — متابعة ختمات القرآن

تطبيق أندرويد لتسجيل القراءة اليومية (الاسم، نوع الختمة، السورة، من آية إلى آية) مع لوحة إحصائيات قابلة للتخصيص.
البيانات تُحفظ على الجهاز فقط ولا يحتاج التطبيق إلى إنترنت.

## الحصول على ملف APK (بدون تثبيت أي برامج)

1. أنشئ حساباً مجانياً على github.com (إن لم يكن لديك).
2. أنشئ مستودعاً جديداً (New repository) باسم `wird`.
3. ارفع **كل محتويات هذا المجلد** إلى المستودع، بما فيها المجلد المخفي `.github`
   (من الكمبيوتر: Add file ← Upload files، اسحب المجلدات وملفاتها).
4. بعد الرفع يبدأ البناء تلقائياً. تابعه من تبويب **Actions** (يستغرق نحو 5 دقائق).
   وإن لم يبدأ: Actions ← Build APK ← Run workflow.
5. عند اكتمال العلامة الخضراء، افتح **Releases** من الصفحة الرئيسية للمستودع،
   وحمّل الملف `wird.apk` مباشرة إلى جوالك وثبّته (فعّل «التثبيت من مصادر غير معروفة» عند الطلب).

> الـ APK الناتج بصيغة debug مناسب للاستخدام الشخصي. للنشر في Google Play تحتاج صيغة AAB موقّعة (أخبرني وأجهّز لك الخطوات).

## تجربة التصميم قبل البناء
افتح `www/index.html` في أي متصفح لتجربة التطبيق كما هو.

## المميزات
- فهرس 114 سورة مع عدد آيات كل سورة، وحساب النسب تلقائياً.
- أربعة أنواع ختمات: قراءة، حفظ، مراجعة، تدبر/تفسير (كل نوع بتقدمه المستقل).
- التداخل لا يُحسب مرتين: إعادة قراءة نفس الآيات لا ترفع النسبة.
- لوحة قابلة للتخصيص: إظهار/إخفاء الودجات، ترتيبها، نصف/كامل العرض، وأشكال مختلفة (دائرة، نصف دائرة، شريط، أعمدة، خط، مساحة)، اختيار سورة معيّنة.
- خريطة السور، تقويم حراري، سلسلة الأيام المتتالية، هدف يومي، تقدير موعد إتمام الختمة.
- ثلاثة أوضاع (تلقائي/فاتح/داكن) وسبعة ألوان، وأرقام عربية اختيارية.
- نسخ احتياطي واستيراد من الإعدادات.
